## v2.1.14 (2026-11-02)

### New
- **Updates adjustable and switchable off (privacy):** Under "Firmware-Update" in the web interface you can choose whether the device asks for new versions: with a notice on the display and in the web interface (as before, default), in the web interface only, or off completely. When off, the device does not contact GitHub and shows no update symbol; the firmware can still be updated with the web installer over USB. You can also set the interval between checks: 1, 6 (default) or 24 hours. The setting is part of the backup. Existing devices keep the previous behaviour.
