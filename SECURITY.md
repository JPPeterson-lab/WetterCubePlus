# Sicherheit / Security

## Deutsch

Hast du eine Sicherheitslücke in **WetterCubePlus** gefunden? Bitte melde sie **vertraulich** und nicht als öffentliches Issue:

- über die private Meldung von GitHub: **Security → Report a vulnerability** in diesem Repository, oder
- per E-Mail an **info@wettercube.de** (Betreff „Sicherheit WetterCubePlus“).

Bitte beschreibe, was du gefunden hast, welche Version betroffen ist (siehe Web-Oberfläche oder `/log`) und wie man es nachstellen kann. Ich antworte, sobald ich kann, und nenne dich auf Wunsch bei der Korrektur. Es handelt sich um ein Hobby-Open-Source-Projekt ohne feste Reaktionszeiten und ohne Prämien.

Hinweise zum sicheren Betrieb stehen in den [Nutzungshinweisen](https://wettercube.de/nutzungshinweise/) und im [Wiki](https://wiki.wettercube.de/index.php/WetterCubePlus/Start). Die Lizenz und die Haftung sind in den [Nutzungshinweisen](https://wettercube.de/nutzungshinweise/) beschrieben.

## English

Did you find a security vulnerability in **WetterCubePlus**? Please report it **confidentially** and not as a public issue:

- through GitHub's private reporting: **Security → Report a vulnerability** in this repository, or
- by email to **info@wettercube.de** (subject "Security WetterCubePlus").

Please describe what you found, which version is affected (see the web interface or `/log`) and how to reproduce it. I will answer as soon as I can and will credit you on request if you like. This is a hobby open-source project without fixed response times and without bounties.

Notes on safe operation are in the [usage notes](https://wettercube.de/en/usage-notes/) and in the [wiki](https://wiki.wettercube.de/index.php/WetterCubePlus/Start). Licence and liability are described in the [usage notes](https://wettercube.de/en/usage-notes/).
