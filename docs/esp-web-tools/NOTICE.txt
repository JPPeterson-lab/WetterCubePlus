esp-web-tools (Installer-Skript fuer den Web-Installer)
=====================================================
Dieser Ordner enthaelt eine unveraenderte Kopie von esp-web-tools 10.4.0 (dist/web) von https://github.com/esphome/esp-web-tools
(Lizenz Apache-2.0, Text in der Datei LICENSE). Die Dateien liegen hier, damit die Installer-Seite beim Aufruf keine Dateien von einem
Drittanbieter (CDN) laden muss.
